# Git Practice

Учебный репозиторий для практики Git и GitHub.

## Файлы

- `README.md` — описание проекта.
- `hello.py` — программа с приветствием.

## Запуск

```bash
python hello.py
```

## Практика

Создать файлы и коммиты, опубликовать их на GitHub, внести изменение в ветке `change` и объединить её с `main`.
